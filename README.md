# My LitVM Token 🚀

A standard, production-ready **ERC-20 token** built using secure smart contract libraries from **OpenZeppelin Contracts**. The token is fully deployed and verified on the network.

## 📝 Token Specifications

* **Token Name:** My Gold Token
* **Token Symbol:** GLD
* **Initial Supply:** 1,000,000 GLD
* **Decimals:** 18
* **Contract Address:** `0xF9dCa8d53F75D7f294380b3A0575DD42c0DC6BC9`

## 🛠 Features Included

- **Standard ERC-20:** Full compliance with the ERC-20 standard, providing support for token transfers, allowances, and balances.
- **Ownable:** Secure access control management powered by OpenZeppelin's `Ownable`.
- **Mintable:** The contract owner (deployer) has exclusive rights to mint additional tokens if needed in the future.
